# Transcription Handoff Packet

## Definition

A transcription handoff packet is a structured engineering artifact created from a recorded meeting, QA session, demo, or bug report.

It includes the original recording, a reviewed transcript, reproduction steps, expected behavior, actual behavior, a timestamped evidence table, environment details, and follow-up questions.

The goal is to turn unstructured audio or video into a package that developers can debug from. In a Daytona workspace, a team can keep the recording, generated transcript, and handoff Markdown file in the same project folder so the evidence remains reproducible and easy to review.
